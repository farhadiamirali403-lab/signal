# ربات کپی سیگنال تلگرام → بروکر

سیگنال‌های کانال تلگرام را می‌خواند — چه متنی و چه **به صورت عکس** — و روی حساب
بروکر تو اجرا می‌کند. حجم را بر اساس درصد ریسک حساب می‌کند، پیام‌های بعدیِ
کانال (ریسک‌فری، بستن نصف، کنسل کردن سیگنال) را هم روی همان پوزیشن اعمال می‌کند.

عکس‌ها با مدل بینایی **Gemini** خوانده می‌شوند و خروجی مدل قبل از تبدیل شدن به
معامله، دوباره اعتبارسنجی می‌شود.

## راه ساده: همه‌چیز با دکمه داخل تلگرام ⭐️

راه‌اندازی داخل خود ربات تلگرامی انجام می‌شود. لازم نیست فایلی را دستی ویرایش کنی.

**روی سرور اوبونتو فقط این سه دستور:**

```bash
git clone https://github.com/farhadiamirali403-lab/signal.git
cd signal
bash deploy/setup_ubuntu.sh
```

اسکریپت فقط سه چیز می‌پرسد:

| چه | از کجا |
|---|---|
| توکن ربات | در تلگرام به @BotFather پیام بده و `/newbot` بزن |
| `api_id` و `api_hash` | my.telegram.org → API development tools |

بعد در تلگرام ربات خودت را باز کن و `/start` بزن. ربات قدم‌به‌قدم می‌پرسد:

1. **اکانت تلگرامت:** دکمه‌ی «ارسال شماره» را بزن و کد ورود را با دکمه‌های عددی وارد کن
2. **کانال سیگنال:** از لیست کانال‌هایت انتخاب کن
3. **کلید Gemini:** کلید را بفرست (پیامت خودکار پاک می‌شود)
4. **حساب معاملاتی:** cTrader با لینک ورود، یا متاتریدر با شماره‌ی حساب و رمز
5. **▶️ روشن کردن ربات**

ریسک، حالت خودکار/با تایید، وضعیت حساب، توقف موقت و بستن همه‌ی پوزیشن‌ها
همه در منوی ربات است.

> اولین کسی که به ربات `/start` بدهد صاحبش می‌شود و ربات بعد از آن به هیچ‌کس دیگر
> جواب نمی‌دهد. پس بلافاصله بعد از نصب `/start` بزن.

**روی ویندوز:** `python -m pip install -r requirements.txt` را بزن، بعد
`python run.py`. همان سه سؤال را می‌پرسد و بعد بقیه‌ی کار در تلگرام است.

راهنمای پایین‌تر روش قدیمی دستی است. پنل هر مقداری را که قبلاً در `.env` یا
`config.yaml` گذاشته باشی هم می‌خواند.

## راه‌اندازی — گام به گام

### ۱. وابستگی‌ها

```bash
python -m pip install -r requirements.txt
```

### ۲. کلیدهای تلگرام

به [my.telegram.org](https://my.telegram.org) برو → API development tools → یک
اپ بساز. `api_id` و `api_hash` را بردار.

بعد در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن و
توکن ربات کنترل را بگیر. (این ربات فقط برای پنل تایید و گزارش‌هاست.)

### ۳. کلید Gemini (برای خواندن عکس‌ها)

سیگنال‌های کانالت عکس هستند، پس ربات باید عکس را بخواند. کلید رایگان را از
[aistudio.google.com/apikey](https://aistudio.google.com/apikey) بگیر.

> **توجه:** اشتراک اپلیکیشن Gemini با کلید API فرق دارد و به درد ربات نمی‌خورد.
> کلید API چیز جدایی است و سقف رایگان روزانه دارد که برای چند سیگنال در روز
> کاملاً کافی است. کلید واقعی با `AIza` شروع می‌شود و حدود ۳۹ کاراکتر است.

**دسترسی به سرویس:** روی این سیستم، اتصال مستقیم به Gemini مسدود است (پاسخ
HTML با کد ۴۰۳). پراکسی محلی که داری این را حل می‌کند و در `.env` تنظیم شده:

```
GEMINI_PROXY=socks5://127.0.0.1:10808
```

پراکسی باید هنگام اجرای ربات بالا باشد. اگر پورت پراکسی‌ات عوض شد، همین خط را
تغییر بده. `python tools/check_vision.py` خودش تشخیص می‌دهد مشکل از کلید است یا
از شبکه.

**انتخاب مدل:** مدل‌های `pro` روی سقف رایگان سهمیه‌ی صفر دارند و کار نمی‌کنند؛
فقط `flash` در دسترس است. مدل تنظیم‌شده `gemini-3.5-flash` است که روی سیگنال
واقعی این کانال تست شد و اعداد چارت را درست خواند. سرویس گاهی شلوغ است
(خطای ۵۰۳) و پراکسی هم گاهی اتصال را قطع می‌کند، برای همین ربات تا سه بار
خودکار تلاش مجدد می‌کند.

### ۴. فایل `.env`

از روی نمونه بساز و پرش کن:

```bash
copy .env.example .env
```

`MT5_LOGIN` / `MT5_PASSWORD` / `MT5_SERVER` را از ترمینال متاتریدر، منوی
File → Open an Account یا Tools → Options → Server بردار.

### ۵. پیدا کردن آیدی کانال

```bash
python tools/list_chats.py
```

اولین اجرا شماره‌ی موبایل و کد تلگرام را می‌پرسد. آیدی کانال سیگنال را در
`config.yaml` بگذار:

```yaml
telegram:
  source_channel: -1001234567890
```

### ۶. آیدی خودت برای پنل کنترل

به ربات کنترلی که ساختی `/start` بده — آیدی عددی‌ات را جواب می‌دهد. همان را در
`config.yaml` → `telegram.control_chat_id` بگذار.

### ۷. اتصال به بروکر

**اگر `broker: ctrader`** — در پنل LiteFinance یک حساب cTrader **دمو** بساز،
بعد در [connect.spotware.com](https://connect.spotware.com) یک اپ ثبت کن
(Redirect URI را دقیقاً `http://localhost/` بگذار) و Client ID و Secret را در
`.env` بگذار. سپس:

```bash
python tools/ctrader_auth.py
```

لینک تایید می‌دهد، کد را برمی‌گردانی، و خودش توکن و شناسه‌ی حساب را در `.env`
می‌نویسد.

**اگر `broker: mt5`** — ترمینال باید باز باشد و `Algo Trading` روشن.

در هر دو حالت، تست بدون باز کردن معامله:

```bash
python tools/check_broker.py
```

### ۸. تست خواندن عکس

```bash
python tools/check_vision.py
```

کلید را چک می‌کند و مدل‌هایی که پشتیبانی می‌شوند را لیست می‌کند. اگر مدل داخل
`config.yaml` در لیست نبود، یکی از لیست را جایگزین کن.

بعد از اینکه با مرحله‌ی بعد چند عکس در `images/` ذخیره شد، می‌توانی تک‌تک
تست‌شان کنی:

```bash
python tools/check_vision.py images/12345.jpg
```

### ۹. تست روی کانال واقعی (مهم‌ترین مرحله)

```bash
python tools/dry_run.py 200 --images 30
```

۲۰۰ پیام آخر کانال را می‌خواند (حداکثر ۳۰ عکس) و برای هرکدام می‌گوید چه فهمیده و
چه معامله‌ای باز می‌شد — **بدون اینکه هیچ معامله‌ای باز شود.**

این مهم‌ترین مرحله است. چیزی که باید در خروجی چک کنی:

- سیگنال‌های واقعی با برچسب `✅ سیگنال` بیایند و اعدادشان با عکس بخواند
- پیام‌های «TP1 خورد» با برچسب `🖼 ... info` بیایند، نه سیگنال
- پیام‌های «کنسل کنید» با برچسب `🔧 دستور مدیریتی` بیایند

عکس‌ها در `images/` ذخیره می‌شوند. اگر چیزی اشتباه خوانده شد، خروجی را نشانم بده
تا درستش کنم.

### ۱۰. اجرا

```bash
python run.py
```

## پنل کنترل (در چت با ربات)

| دستور | کار |
|---|---|
| `/status` | بالانس، اکوییتی، سود/زیان امروز، تعداد پوزیشن |
| `/pause` | توقف؛ سیگنال‌ها فقط گزارش می‌شوند |
| `/resume` | ادامه |
| `/closeall` | بستن همه‌ی پوزیشن‌های باز شده توسط ربات |
| `/id` | آیدی عددی چت |

**حالت فعلی `auto` است:** هر سیگنال و هر دستور کانال بدون پرسیدن اجرا می‌شود.
بعد از هر اجرا، عکس اصلی همراه گزارش کامل برایت فرستاده می‌شود تا بتوانی چک کنی
درست خوانده شده. با `/pause` هر لحظه می‌توانی متوقفش کنی.

اگر خواستی برگردی به حالت تایید دستی، در `config.yaml` مقدار `mode` را
`confirm` کن — آن‌وقت هر سیگنال با دو دکمه‌ی «✅ اجرا کن / ❌ رد کن» می‌آید.

## تنظیمات مهم `config.yaml`

| کلید | معنی |
|---|---|
| `mode` | `auto` (خودکار، فعلاً همین) یا `confirm` (با تایید دستی) |
| `risk_percent` | درصد بالانس که روی هر سیگنال ریسک می‌شود |
| `max_open_positions` | سقف پوزیشن هم‌زمان |
| `max_daily_loss_percent` | بعد از این ضرر روزانه، تا فردا معامله‌ای باز نمی‌شود |
| `tp_strategy` | `split` حجم را بین TPها تقسیم می‌کند، `first`/`last` یک پوزیشن می‌زند |
| `max_tps` | حداکثر تارگتی که پوشش داده می‌شود (۶) |
| `tp_selection` | اگر حجم به همه‌ی تارگت‌ها نرسید: `nearest` / `spread` / `farthest` |
| `market_threshold_pips` | فاصله‌ی بیشتر از این، اردر پندینگ می‌شود نه مارکت |
| `max_slippage_pips` | اگر بازار بیش از این از قیمت سیگنال دور شده، اجرا نمی‌شود |
| `max_signal_age_seconds` | سیگنال قدیمی‌تر از این، اجرا نمی‌شود |
| `whitelist` | فقط این نمادها اجازه‌ی معامله دارند |
| `vision.model` | مدل خواندن عکس؛ `gemini-2.5-pro` دقیق‌تر، `gemini-2.5-flash` ارزان‌تر |
| `vision.min_confidence` | اطمینان کمتر از این = سیگنال اجرا نمی‌شود |
| `vision.enabled` | اگر خاموش باشد، عکس‌ها فقط برایت فوروارد می‌شوند |

## فرمت سیگنال‌های این کانال

سیگنال‌ها اسکرین‌شات TradingView هستند با باکس پوزیشن که روی آن `entry` / `sl` /
`TP1` / `TP2` با عدد نوشته شده، و کپشن نماد و نوع اردر را می‌گوید:

```
XAUUSD
buystop
```

پرامپت مدل مخصوص همین فرمت نوشته شده و صریحاً گفته شده که اعداد محور قیمت،
هدر OHLC و اندیکاتورها را نادیده بگیرد — چون اشتباه گرفتن آن‌ها یعنی معامله‌ی
اشتباه.

`buystop` / `selllimit` و مانند آن به عنوان اردر پندینگ ثبت می‌شوند و ربات منتظر
می‌ماند قیمت به باکس برسد — دقیقاً همان قاعده‌ای که در پیام پین‌شده‌ی کانال آمده.
اگر تا لحظه‌ی ثبت، قیمت از باکس رد شده باشد، ربات اردر را نمی‌گذارد و دلیلش را
می‌گوید.

پیام‌های بعدی کانال ریپلای به خود سیگنال هستند، پس به پوزیشن درست وصل می‌شوند:

| کپشن | اقدام ربات |
|---|---|
| `riskfree` | حد ضرر روی نقطه‌ی ورود |
| `TP1✅` / `TP2✅` | فقط گزارش، بدون اقدام |
| `کنسل` | لغو اردر پندینگ |

## سیگنال‌های چندتارگتی

بعضی سیگنال‌های این کانال ۲ تارگت دارند و بعضی تا ۶ تا. حجم کل (که از روی ریسک
حساب می‌شود) بین تارگت‌ها تقسیم می‌شود و هر بخش یک پوزیشن جدا با حد سود خودش
است. حد ضرر همه یکی است.

**محدودیت واقعی:** هر پوزیشن باید از حداقل حجم بروکر (معمولاً ۰.۰۱ لات) بزرگ‌تر
باشد. اگر حجم کلت ۰.۰۲ لات باشد، بیشتر از ۲ بخش ممکن نیست — هرچقدر هم کانال
تارگت بدهد.

در آن حالت ربات **خودش کم می‌کند ولی بی‌صدا نه**: در پیام تایید می‌نویسد

```
⚠️ کانال 6 تارگت داد ولی حجم فقط 2 بخش را می‌کشد — انتخاب‌شده: 3352، 3360
```

کدام تارگت‌ها انتخاب شوند با `tp_selection` تعیین می‌شود:

| مقدار | از ۶ تارگت، ۲ بخش | مناسب چه کسی |
|---|---|---|
| `nearest` | TP1، TP2 | سود زودتر قفل شود (پیش‌فرض) |
| `spread` | TP1، TP6 | یک بخش سود زود، یک بخش رانر |
| `farthest` | TP5، TP6 | سود بیشتر، برخورد کمتر |

هرچه بالانس حسابت بالاتر برود، بخش‌های بیشتری ممکن می‌شود و این محدودیت
خودبه‌خود برداشته می‌شود.

## محافظ‌هایی که فعالند

- **خروجی مدل بینایی هیچ‌وقت مستقیم معامله نمی‌شود:** هر عددی که از عکس خوانده
  می‌شود دوباره اعتبارسنجی می‌شود، و اگر اطمینان مدل زیر `min_confidence` باشد
  سیگنال اجرا نمی‌شود
- عکس اصلی همراه هر پیشنهاد برایت فرستاده می‌شود تا قبل از تایید خودت ببینی
- «TP1 خورد» و گزارش‌های سود هرگز باعث باز یا بسته شدن معامله نمی‌شوند
- تارگت‌های پوشش‌داده‌نشده هیچ‌وقت بی‌صدا دور ریخته نمی‌شوند — در پیام تایید گزارش می‌شوند
- سیگنال بدون حد ضرر رد می‌شود (`require_sl`)
- اعداد بی‌معنی رد می‌شوند: حد ضرر بالای قیمت ورود در خرید و برعکس
- هر پیام فقط یک بار اجرا می‌شود (دیتابیس `state.db`)
- سقف ضرر روزانه و سقف تعداد پوزیشن
- کنترل لغزش قیمت و کهنگی سیگنال
- رعایت حداقل فاصله‌ی مجاز بروکر برای SL/TP
- ربات فقط پوزیشن‌های خودش (با `magic`) را می‌بندد و دست به معاملات دستی‌ات نمی‌زند

## نکته‌های واقعی

- ترمینال متاتریدر باید همیشه باز و لاگین باشد؛ ربات از طریق همان ترمینال معامله می‌کند.
- اگر کامپیوترت خاموش شود ربات هم می‌خوابد. برای اجرای ۲۴ ساعته راهنمای کامل
  [deploy/SETUP_VPS.md](deploy/SETUP_VPS.md) را ببین — شامل ری‌استارت خودکار،
  اجرای بعد از بوت، و نکته‌ی مهم اینکه ورود تلگرام باید روی خود سرور انجام شود.
- «پیپ» برای طلا در این پروژه `0.1` در نظر گرفته شده (یعنی ۱۰ پیپ = ۱ دلار حرکت).
  اگر کانالت جور دیگری حساب می‌کند، در `signalbot/mt5_client.py` مقدار
  `_PIP_OVERRIDES` را عوض کن.
- هر عکس یک فراخوانی به Gemini است. برای چند سیگنال در روز، سقف رایگان کافی است.
- اگر کانال «کنسل کنید» را بدون ریپلای به سیگنال بفرستد، ربات از روی نماد و قیمتِ
