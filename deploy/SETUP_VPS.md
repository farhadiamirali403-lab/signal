# راه‌اندازی روی سرور مجازی (۲۴ ساعته)

## چرا ویندوز

کتابخانه‌ی رسمی متاتریدر ۵ برای پایتون **فقط روی ویندوز** کار می‌کند و از طریق
ترمینال متاتریدر معامله می‌کند. پس VPS باید ویندوز باشد — لینوکس جواب نمی‌دهد.

**مشخصات کافی:**

| منبع | حداقل | راحت |
|---|---|---|
| CPU | ۲ هسته | ۲ هسته |
| RAM | ۴ گیگ | ۸ گیگ |
| دیسک | ۵۰ گیگ SSD | ۸۰ گیگ |
| سیستم | Windows Server 2019/2022 یا Windows 10/11 | — |

**محل سرور:** جایی خارج از ایران بگیر. علاوه بر پینگ بهتر به بروکر، مشکل
دسترسی به Gemini هم خودبه‌خود حل می‌شود و دیگر به پراکسی نیاز نداری. اگر سرور
نزدیک سرور بروکر (معمولاً لندن یا نیویورک) باشد، اجرای اردرها سریع‌تر است.

---

## گام ۱ — نصب پیش‌نیازها روی VPS

با Remote Desktop به سرور وصل شو و نصب کن:

1. **Python 3.13** از [python.org](https://www.python.org/downloads/) —
   موقع نصب حتماً تیک **Add python.exe to PATH** را بزن.
2. **ترمینال متاتریدر ۵ بروکرت** (LiteFinance) و وارد حسابت شو.

## گام ۲ — انتقال پروژه

کل پوشه‌ی پروژه را روی سرور کپی کن (مثلاً در `C:\SignalBot`).

**این‌ها را کپی نکن:**

- `sessions/` — نشست تلگرام باید روی خود سرور ساخته شود (گام ۴)
- `state.db` — دیتابیس معاملات، روی سرور از صفر ساخته می‌شود
- `logs/`, `images/`, `__pycache__/`

`.env` و `config.yaml` را حتماً کپی کن.

بعد روی سرور:

```bash
python -m pip install -r requirements.txt
```

## گام ۳ — تنظیم `.env` برای سرور

دو چیز عوض می‌شود:

```
# سرور خارج از ایران است، پراکسی لازم نیست — این خط را کامنت کن
# GEMINI_PROXY=socks5://127.0.0.1:10808
```

اگر سرور داخل ایران گرفتی، پراکسی همان سرور را اینجا بگذار.

بقیه‌ی مقادیر (کلید تلگرام، کلید Gemini، حساب متاتریدر) همان‌هاست.

تست کن که هر دو سرویس از سرور در دسترس‌اند:

```bash
python tools/check_vision.py
```

```bash
python tools/check_mt5.py
```

## گام ۴ — ورود تلگرام روی خود سرور

**این مهم‌ترین نکته است.** فایل نشست را از کامپیوتر خودت کپی نکن — تلگرام ورود
از IP جدید با نشست قدیمی را مشکوک می‌داند و ممکن است نشست را باطل کند. روی خود
سرور اجرا کن:

```bash
python tools/list_chats.py
```

شماره و کدی که تلگرام می‌فرستد را وارد کن. یک بار انجام می‌شود و بعد نشست در
`sessions/user.session` می‌ماند.

> کانال خصوصی‌ات با همین نشست خوانده می‌شود، چون این نشست **اکانت خودت** است.
> ربات BotFather هیچ دسترسی‌ای به کانال ندارد و فقط پنل تایید است.

از خروجی همین دستور، آیدی کانال را بردار و در `config.yaml` بگذار (اگر قبلاً
گذاشته‌ای، لازم نیست دوباره).

## گام ۵ — تنظیم متاتریدر برای اجرای بی‌نظارت

در ترمینال متاتریدر روی سرور:

1. `Tools → Options → Expert Advisors` → تیک **Allow Algorithmic Trading**
2. `Tools → Options → Server` → تیک **Keep personal settings and data at startup**
3. ترمینال را در Startup ویندوز بگذار تا بعد از ری‌استارت خودش بالا بیاید:
   میانبر ترمینال را کپی کن و در این مسیر بچسبان:
   `Win+R` → `shell:startup`

> متاتریدر باید همیشه باز و لاگین باشد. ربات از طریق همین ترمینال معامله می‌کند.

## گام ۶ — اجرای خودکار ربات

PowerShell را **as Administrator** باز کن:

```bash
powershell -ExecutionPolicy Bypass -File deploy\install_autostart.ps1
```

این یک تسک ویندوزی می‌سازد که بعد از هر ورود به ویندوز، ربات را با
`deploy\run_bot.bat` اجرا می‌کند. آن فایل یک حلقه‌ی ری‌استارت دارد: اگر ربات به
هر دلیلی بسته شد، ۱۵ ثانیه بعد خودش دوباره بالا می‌آید.

**ورود خودکار به ویندوز** را هم فعال کن تا بعد از ری‌استارت سرور، بدون RDP زدن
تو همه‌چیز بالا بیاید:

```bash
netplwiz
```

تیک «Users must enter a user name and password» را بردار و رمز را وارد کن.

## گام ۷ — جلوگیری از خوابیدن و ری‌استارت ناگهانی

```bash
powercfg /change standby-timeout-ac 0
```

```bash
powercfg /change hibernate-timeout-ac 0
```

در `Settings → Windows Update → Advanced options` ساعات فعال را طوری تنظیم کن
که ری‌استارت خودکار وسط ساعات معاملاتی نیفتد.

---

## نکته‌ی مهم درباره‌ی RDP

وقتی کارت تمام شد، پنجره‌ی Remote Desktop را **ببند** (Disconnect)، اما
**Sign out نکن**. با Sign out نشست ویندوز بسته می‌شود و متاتریدر و ربات هر دو
می‌میرند. با Disconnect ساده همه‌چیز پشت صحنه ادامه می‌دهد.

---

## چک کردن اینکه زنده است

از تلگرام، به ربات کنترلت بزن:

```
/status
```

بالانس، اکوییتی، سود/زیان امروز و تعداد پوزیشن را جواب می‌دهد. اگر جواب نداد،
یعنی ربات بالا نیست.

هر بار که ربات بالا می‌آید یک پیام «🚀 ربات راه افتاد» می‌فرستد. اگر این پیام را
پشت سر هم زیاد دیدی، یعنی ربات دارد کرش می‌کند و ری‌استارت می‌شود — لاگ را ببین:

```bash
type logs\signalbot.log
```

```bash
type logs\restarts.log
```

## چیزهایی که خودکار مدیریت می‌شوند

- **قطع شدن متاتریدر:** ربات هر ۳۰ ثانیه وضعیت را چک می‌کند و اگر ترمینال قطع
  شده باشد خودش دوباره وصل می‌شود و بهت خبر می‌دهد.
- **قطع شدن تلگرام:** Telethon خودش دوباره وصل می‌شود.
- **شلوغی سرویس Gemini:** تا سه بار تلاش مجدد، و اگر باز نشد عکس را برایت
  می‌فرستد تا دستی تصمیم بگیری.
- **کرش کامل ربات:** حلقه‌ی `run_bot.bat` آن را دوباره بالا می‌آورد.

## چیزهایی که خودکار نیستند

- اگر رمز حساب متاتریدر عوض شود، باید `.env` را دستی به‌روز کنی.
- اگر سقف رایگان Gemini تمام شود، تا روز بعد عکس‌ها خوانده نمی‌شوند (ربات
  عکس را برایت می‌فرستد و خبر می‌دهد).
- اگر تلگرام نشست را باطل کند (مثلاً از تنظیمات امنیتی خودت)، باید دوباره
  `python tools/list_chats.py` را روی سرور بزنی.
